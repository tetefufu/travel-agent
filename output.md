# Output Format

## General Rules
- Output as a **self-contained HTML file** with embedded CSS — no markdown
- Include images inline (embed via URL in `<img>` tags)
- No fluff, no preamble, no "quick take" sections
- Use bullet points, not prose sentences
- Short, punchy statements — strip filler words
- Opinionated: make clear recommendations, don't hedge

## Country Folder
- eg sri lanka
- extract all text from all images
- consolidate and sort into tips, places
- places: sort between places to eat, places to visit, hotels/spas
- add these to sumary

## Structure & Sections

### Best Time to Go
- Table: month, weather, crowds, price level
- Flag Eid dates if they align. Example: "Eid al-Adha: Jun 6–7. Perfect. June is best. **Strongly recommend.**"
- Note any periods to avoid in one line

### Flights (Dubai → Destination)
- Table: Economy vs Business, price in AED, airlines, duration
- Seasonal price variation: short bullet list or simple table
- No prose descriptions

### Hotels
- Table only: Hotel name | Tier | Price/night (AED) | Total (AED, for planned nights) | Pool | TripAdvisor rating | Link
- No written descriptions
- Include pool quality as a column (emoji or short tag: ✅ Excellent / ⚠️ Average / ❌ None)
- Photos: embed 1 pool photo + 1 bathroom photo per shortlisted hotel (below the table, labelled)
- Show total = price/night × nights planned at that property

### Itinerary
- Day-by-day: **Day 1 — Location**
- Morning / Afternoon / Evening as sub-bullets
- One line per activity, no descriptions
- Include 1 hero image per day (landmark or activity photo)

### Food & Restaurants
- Table: Restaurant | Cuisine | Type (fine/street/local) | Vegetarian? | Link
- No descriptions

### Instagram Spots
- Bullet list of locations + 1 image each
- image on left of text in roughly standard perspective aspect ratio

### Events
- Bullet list: Event name — dates — type
- Only if relevant to travel window

### Practical Info
- Bullet list only: Visa, Currency, Tipping, Getting around

### Google Maps
- Single link to a curated Google Maps list or instructions to build one

### Budget Summary
- Table: Flights | Hotels | Activities/transport | **Total**
- **Exclude food & dining** — not an incremental travel cost
- Show low and high range in AED
- Add footnote: X% of combined monthly income (70,000 AED)

---

## HTML Style Guidelines
- Clean, modern design — white background, dark text
- Section headers: large, bold, with a subtle divider line
- Tables: minimal borders, alternating row shading
- Images: rounded corners, max-width contained, with captions
- Mobile-friendly layout
- Color accent: deep navy (#1a2e4a) for headers, gold (#c9a84c) for highlights
